# Give three test cases for a function that reads a natural number from standard input. Include at least one corner case.

# Answer

1. Standard Case: The user inputs the string `42` followed by Enter. The function successfully reads the digits and returns the natural number `42`.
2. Corner Case (Zero): The user inputs `0` followed by Enter. This tests how the function handles the boundary condition of zero.
3. Corner Case (Invalid Input): The user inputs `-5` or `abc` followed by Enter. This tests how the function handles negative numbers or non-numeric characters which are not valid natural numbers.
